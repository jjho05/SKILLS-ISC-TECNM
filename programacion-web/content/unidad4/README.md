# Unidad 4: Programación del Lado del Servidor

## Descripción

Esta unidad traslada el desarrollo al servidor. Aprenderás a construir APIs robustas usando Node.js, Express y bases de datos, entendiendo la arquitectura del backend moderno.

## Contenido

### [4.1 Introducción a Node.js](4.1.md)
- Runtime de JavaScript V8
- Event Loop y Asincronía
- NPM (Node Package Manager)

### [4.2 Estructuras de control Backend](4.2.md)
- Modularización (CommonJS vs ES Modules)
- File System (`fs`)
- Streams y Buffers

### [4.3 Protocolo HTTP y Express](4.3.md)
- Verbos HTTP (GET, POST, PUT, DELETE)
- Códigos de Estado
- Routing y Middlewares en Express

### [4.4 Manejo de objetos del servidor (Request/Response)](4.4.md)
- `req.body`, `req.params`, `req.query`
- Headers y Cookies
- Validación de datos (Joi/Zod)

### [4.5 Creación de Clases y Arquitectura](4.5.md)
- Patrón MVC en Backend
- Servicios y Controladores
- Inyección de Dependencias

### [4.6 Acceso a Datos (Bases de Datos)](4.6.md)
- Conexión a Bases de Datos (SQL vs NoSQL)
- ORMs (Sequelize / Prisma / Mongoose)
- CRUD completo y Transacciones

## Objetivos de Aprendizaje

Al completar esta unidad, serás capaz de:
- ✅ Configurar un servidor web con Node.js y Express.
- ✅ Diseñar APIs RESTful profesionales.
- ✅ Conectar tu aplicación a una Base de Datos.
- ✅ Implementar la arquitectura MVC en el Backend.

## Recursos Adicionales

- **Docs:** Expressjs.com, Nodejs.org.
- **Herramientas:** Postman, Thunder Client.
- **Tiempo estimado:** 15-20 horas.
