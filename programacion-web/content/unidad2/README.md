# Unidad 2: Maquetado Web

## Descripción

Esta unidad se enfoca en la estructura y presentación de las páginas web. Aprenderás a crear documentos semánticos con HTML5 y a aplicar estilos profesionales con CSS3.

## Contenido

### [2.1 Introducción a HTML](2.1.md)
- Estructura básica del documento
- Etiquetas semánticas y atributos
- DOM (Document Object Model)

### [2.2 Estructura global](2.2.md)
- `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- Metadatos y SEO básico
- Enlaces y rutas

### [2.3 Elementos básicos](2.3.md)
- Títulos, Párrafos, Listas
- Imágenes y Multimedia
- Tablas y Contenedores (`div`, `span`)

### [2.4 Formularios](2.4.md)
- `input`, `select`, `textarea`, `button`
- Validaciones HTML5
- Accesibilidad en formularios

### [2.5 Lenguajes de presentación (CSS)](2.5.md)
- Sintaxis CSS y formas de inclusión
- Cascada y Especificidad
- Herencia

### [2.6 Selectores](2.6.md)
- Clases, IDs y Etiquetas
- Pseudoclases y Pseudoelementos
- Combinadores

### [2.7 Modelo de caja](2.7.md)
- Margin, Border, Padding, Content
- `box-sizing: border-box`
- Layouts modernos (Flexbox y Grid)

## Objetivos de Aprendizaje

Al completar esta unidad, serás capaz de:
- ✅ Crear páginas web semánticas con HTML5.
- ✅ Diseñar formularios interactivos y accesibles.
- ✅ Aplicar estilos CSS3 para diseño visual.
- ✅ Dominar Flexbox y CSS Grid para layouts responsivos.

## Recursos Adicionales

- **Herramientas:** VS Code, Chrome DevTools.
- **Práctica:** Flexbox Froggy, Grid Garden.
- **Tiempo estimado:** 10-12 horas.
