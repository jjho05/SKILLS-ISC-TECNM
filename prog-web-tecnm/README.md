## 📋 Descripción

Este repositorio contiene material educativo **profesional y completo** para la asignatura **Programación Web (AEB-1055)** del Tecnológico Nacional de México (TecNM). Cubre todo el stack de desarrollo moderno, desde el maquetado básico hasta el despliegue en la nube. Incluye:

- ✅ **31 archivos** de contenido teórico en Markdown.
- ✅ **Documentación detallada** de HTML5, CSS3, JS (ES6+), Node.js y Cloud Computing.
- ✅ **Códigos de ejemplo** funcionales para cada unidad.
- ✅ **100% alineado** con el temario oficial TecNM.
- ✅ **5 unidades** completas listas para estudiar o impartir clase.

## 🎓 Competencias del Curso

Al completar este curso, serás capaz de:

1. ✅ **Construir** sitios web semánticos y responsivos.
2. ✅ **Programar** lógica de negocio en el cliente con JavaScript moderno.
3. ✅ **Desarrollar** APIs RESTful robustas con Node.js y Express.
4. ✅ **Implementar** seguridad y patrones de diseño en aplicaciones web.
5. ✅ **Desplegar** soluciones en la nube (AWS/PaaS) siguiendo estándares de industria.

## 🚀 Inicio Rápido

### Prerrequisitos

```bash
# Node.js 18 o superior
node --version

# Navegador Moderno (Chrome/Firefox)
```

### Ejecutar Ejemplo de API (Unidad 4)

```bash
# 1. Navegar a la carpeta
cd content/unidad4/codigos/

# 2. Instalar dependencias
npm install

# 3. Correr servidor
npm start
# Server running at http://localhost:3000
```

## 💻 Ejemplos de Código

### Unidad 3: Manipulación del DOM (JS)

```javascript
document.getElementById('btn').addEventListener('click', () => {
    const tarea = document.querySelector('input').value;
    const items = JSON.parse(localStorage.getItem('tareas')) || [];
    items.push(tarea);
    localStorage.setItem('tareas', JSON.stringify(items));
    render();
});
```

### Unidad 4: API Express Básica
(Ejemplo Simplificado)
```javascript
const express = require('express');
const app = express();

app.get('/api/users', (req, res) => {
    res.json([{ id: 1, name: "Jesús" }]);
});

app.listen(3000, () => console.log('API Ready'));
```

## 📝 Cómo Usar Este Recurso

### Para Estudiantes
1.  **Fundamentos**: Lee la Unidad 1 y 2.
2.  **Práctica**: Clona el repo y modifica los códigos de `unidad2/codigos`.
3.  **Avanzado**: Intenta desplegar la API de la Unidad 4 usando los conceptos de la Unidad 5.

### Para Profesores
1.  **Clases**: Usa los archivos Markdown como base para diapositivas.
2.  **Laboratorio**: Los códigos de ejemplo sirven como práctica de 1 hora.
3.  **Evaluación**: Los temas de Unidad 5 (Seguridad/Cloud) son ideales para proyectos finales.
