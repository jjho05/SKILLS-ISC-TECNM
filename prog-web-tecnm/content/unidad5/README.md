# Unidad 5: Cómputo en la Nube y Servicios

## Descripción

Esta unidad final explora el despliegue y la arquitectura en la nube. Aprenderás sobre los modelos de servicio (IaaS, PaaS, SaaS), patrones de diseño para sistemas distribuidos y seguridad en la nube.

## Contenido

### [5.1 Conceptos generales](5.1.md)
- Definición de Cloud Computing
- Modelos de Despliegue (Pública, Privada, Híbrida)
- Economía de la Nube (CapEx vs OpEx)

### [5.2 Tipos de servicios en la nube](5.2.md)
- IaaS (EC2), PaaS (Heroku), SaaS (Gmail)
- FaaS (Serverless) y CaaS (Kubernetes)
- Matriz de decisión de servicios

### [5.3 Patrones de diseño](5.3.md)
- 12-Factor App
- Microservicios vs Monolitos
- Circuit Breaker, Retry, Saga, CQRS

### [5.4 Estándares en servicios](5.4.md)
- REST vs SOAP vs GraphQL vs gRPC
- WebSockets y HTTP/3
- OpenAPI (Swagger) y AsyncAPI

### [5.5 Plataformas tecnológicas](5.5.md)
- AWS vs Azure vs GCP
- Plataformas para Developers (Vercel, Render)
- Infraestructura como Código (Terraform)

### [5.6 Seguridad e interoperabilidad](5.6.md)
- Modelo de Responsabilidad Compartida
- IAM, OAuth 2.0 y OIDC
- OWASP Top 10 Cloud y Supply Chain Attacks

## Objetivos de Aprendizaje

Al completar esta unidad, serás capaz de:
- ✅ Distinguir entre los diferentes modelos de servicio en la nube.
- ✅ Arquitectar sistemas distribuidos usando patrones modernos.
- ✅ Elegir la plataforma tecnológica adecuada para cada proyecto.
- ✅ Asegurar aplicaciones en la nube siguiendo estándares internacionales.

## Recursos Adicionales

- **Certificaciones:** AWS Cloud Practitioner.
- **Libros:** "Building Microservices" (Sam Newman).
- **Herramientas:** Terraform, Docker, AWS Console.
- **Tiempo estimado:** 10-15 horas.
