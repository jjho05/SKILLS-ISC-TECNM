# Unidad 0: Taller Inicial (Onboarding) 🚀

> "La programación no es sobre lo que sabes, es sobre lo que puedes averiguar."

Bienvenido al **Taller Inicial de Programación Web**.
Esta unidad ha sido diseñada como un **Mini-Curso Intensivo ("Bootcamp")** para llevarte de cero a escribir tu primer código funcional en HTML5 y JavaScript.

No vamos a ver teoría aburrida sin sentido. Vamos a ver **fundamentos profesionales** que usarás el resto de tu carrera.

---

## 📚 Índice del Taller

### 🛠️ 1. Configuración del Entorno
*   **[0.1 HTML Editors (Tu Cabina de Mando)](0.1_html_editors.md)**
    *   *Temas:* IDE vs Editor de Texto, Instalación paso a paso de Antigravity, Extensiones vitales (Live Server), Shortcuts.

### 🏗️ 2. Fundamentos de HTML5
*   **[0.2 HTML Basic (Anatomía Web)](0.2_html_basic.md)**
    *   *Temas:* La estructura "Boilerplate", DOCTYPE, Metadatos (`<head>`) vs Contenido (`<body>`), SEO básico.
*   **[0.3 Elements & Attributes (Ladrillos)](0.3_html_elements_attributes.md)**
    *   *Temas:* Elementos de Bloque vs Línea (Block vs Inline), Atributos Globales (`id`, `class`), Anidamiento correcto.
*   **[0.4 Headings & Paragraphs (Tipografía)](0.4_html_headings_paragraphs.md)**
    *   *Temas:* Jerarquía H1-H6, Colapso de espacios en blanco, Semántica (`<strong>` vs `<b>`).

### 🎨 3. Diseño y Multimedia
*   **[0.5 Styles & Colors (CSS Intro)](0.5_html_styles_colors.md)**
    *   *Temas:* Atributo `style`, Teoría del Color (Hex, RGB), Fuentes (`font-family`).
*   **[0.6 Images & Links (Conectividad)](0.6_html_images_links.md)**
    *   *Temas:* Rutas Absolutas vs Relativas (El error #1), Formatos de imagen (JPG, PNG, SVG, WebP).

### 🧠 4. Lógica y Comportamiento
*   **[0.7 JavaScript (Interactividad)](0.7_html_javascript.md)**
    *   *Temas:* La triada (HTML-CSS-JS), Manipulación del DOM, Eventos (`onclick`).
