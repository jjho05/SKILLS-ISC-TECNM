# 3.4. Manipulación de Objetos (DOM & APIs)

JavaScript sin objetos no sirve de nada.
Aquí aprenderás a manipular el navegador, la memoria y los datos.

---

## 1. El DOM (Document Object Model)

El DOM es la representación en memoria de tu HTML. Es un árbol de objetos.
`<html>` es el root. `<body>` es un hijo.

### 1.1 Selección de Elementos (La Forma Moderna)
Olvida `getElementById` (a menos que necesites rendimiento extremo).
Usa la API de Selectores CSS.

```javascript
// Selecciona el PRIMERO que encuentre (como CSS)
const btn = document.querySelector('.btn-primary');

// Selecciona TODOS (NodeList)
const items = document.querySelectorAll('li.active');

// Convertir NodeList a Array real (para usar .map)
const itemsArray = [...items];
```

### 1.2 Modificando Elementos
Manipular el DOM es "costoso" (re-paints). Hazlo con cuidado.

*   **Texto:** `el.textContent = "Hola"` (Seguro). Evita `innerHTML` (Riesgo XSS).
*   **Clases:**
    ```javascript
    el.classList.add('active');
    el.classList.remove('hidden');
    el.classList.toggle('dark-mode');
    ```
*   **Datos (Data Attributes):**
    ```html
    <div id="user" data-id="123" data-role="admin"></div>
    ```
    ```javascript
    const user = document.querySelector('#user');
    console.log(user.dataset.id); // "123"
    console.log(user.dataset.role); // "admin"
    ```

## 2. Traversing (Navegando el Árbol)

A veces tienes el elemento Hijo y quieres llegar al Abuelo.

### 2.1 Hacia Arriba (`closest`)
El método más útil y menos conocido. Busca el ancestro más cercano que cumpla el selector.
```javascript
// Imagina un click en un icono dentro de un botón dentro de un form
e.target.closest('form'); // Encuentra el formulario, subiendo por el árbol
```

### 2.2 Hacia los Lados y Abajo
*   `el.children`: Hijos directos (HTMLCollection).
*   `el.nextElementSibling`: El siguiente hermano (`div` -> `span`).
*   `el.parentElement`: El padre directo.

## 3. Creación Eficiente (Evita el Reflow)

Si vas a crear 100 `<li>`, no los insertes uno por uno. El navegador repintará 100 veces.

### 3.1 `DocumentFragment` (El DOM Fantasma)
Un contenedor que no está en la pantalla.
```javascript
const fragmento = document.createDocumentFragment();

for (let i = 0; i < 100; i++) {
    const li = document.createElement('li');
    li.textContent = `Item ${i}`;
    fragmento.appendChild(li); // Memoria (Rápido)
}

document.ul.appendChild(fragmento); // Pantalla (1 solo Repaint)
```

## 4. Eventos (El Alma de la Interactividad)

### 4.1 `addEventListener`
Nunca uses `onclick="..."` en el HTML. Ensucia y solo permite un manejador.
```javascript
btn.addEventListener('click', (e) => {
    console.log('Click en', e.target);
});
```

### 4.2 Event Delegation (Delegación de Eventos)
Si tienes una lista de 1000 items, **NO** pongas 1000 Listeners.
Pon 1 Listener en el Padre (`ul`).

```javascript
document.querySelector('ul').addEventListener('click', (e) => {
    // ¿El click fue en un botón?
    if (e.target.matches('button.delete')) {
        const id = e.target.closest('li').dataset.id;
        borrarItem(id);
    }
});
```
*   **Ventaja:** Menos memoria. Funciona con elementos creados dinámicamente en el futuro.

## 5. Propagación de Eventos (Bubbling y Capturing)

Cuando haces clic en un botón, no solo haces clic en él. Haces clic en su padre, en el body, y en el html.

### 5.1 Fases del Evento
1.  **Capturing (Bajada):** Desde el `window` hasta el elemento. (Raramente usado).
2.  **Target:** El evento llega al elemento.
3.  **Bubbling (Subida):** Desde el elemento hasta el `window`. (Aquí funciona el Event Delegation).

### 5.2 Controlando el Flujo
*   `e.stopPropagation()`: *"Detente aquí. No avises a mis padres."*
    *   **Peligro:** Puede romper Analytics o tooltips que dependen de escuchar clicks en el body.
*   `e.preventDefault()`: *"No hagas tu acción por defecto."*
    *   Evita que un Form se envíe y recargue.
    *   Evita que un Link navegue.

## 6. Manipulación Avanzada de Objetos

No todo es `obj.propiedad`. La API de `Object` es poderosa.

### 6.1 Iteración (`Object.keys`, `.values`, `.entries`)
Los objetos no son iterables con `for...of` directamente.
```javascript
const user = { name: "Jesús", role: "Dev", age: 30 };

// Keys (Nombres de propiedad)
Object.keys(user).forEach(key => console.log(key)); // "name", "role", "age"

// Values (Valores)
console.log(Object.values(user)); // ["Jesús", "Dev", 30]

// Entries (Array de Arrays [key, value])
Object.entries(user).forEach(([key, val]) => {
    console.log(`${key}: ${val}`);
});
```

### 6.2 Inmutabilidad Real (`Object.freeze` vs `const`)
*   `const`: No puedes reasignar la variable. Pero puedes cambiar propiedades.
*   `Object.freeze(obj)`: Congela el objeto. Nadie puede cambiar, borrar o agregar propiedades.
    *   **Nota:** Es "Shallow" (no congela objetos anidados dentro).

### 6.3 Clonado y Mezcla (`Object.assign`)
Antes del Spread Operator (`...`), usábamos esto.
```javascript
const defaults = { skin: 'default', sound: true };
const userConfig = { skin: 'dark' };

// Mezcla userConfig sobre defaults
const config = Object.assign({}, defaults, userConfig); 
// { skin: 'dark', sound: true }
```

## 7. JSON (JavaScript Object Notation)

El lenguaje universal de intercambio de datos.

### 7.1 Serialización (`JSON.stringify`)
Convierte Objeto -> Texto.
```javascript
const data = { id: 1, date: new Date() };
const json = JSON.stringify(data);
// '{"id":1, "date":"2025-01-26T..."}'
```
*   **Truco:** `JSON.stringify(obj, null, 2)` formatea el JSON bonito con indentación.

### 7.2 Deserialización (`JSON.parse`)
Convierte Texto -> Objeto.
```javascript
const obj = JSON.parse(json);
// OJO: Las fechas vuelven como STRING, no como Date Objects.
```

### 7.3 Deep Clone Hack
La forma más barata de clonar un objeto complejo (perdiendo fechas y funciones).
```javascript
const clon = JSON.parse(JSON.stringify(original));
```
*   **2025 Standard:** Usa `structuredClone(original)` que sí soporta Fechas y Mapas.

## 8. Almacenamiento en el Navegador (Storage API)

La RAM se borra al cerrar la pestaña. ¿Cómo guardo datos persistentes?

### 8.1 LocalStorage vs SessionStorage
Ambos tienen la misma API (`setItem`, `getItem`). Solo guardan **Strings**.
*   **LocalStorage:** Persiste "para siempre" (hasta que se borre caché).
*   **SessionStorage:** Muere al cerrar la **pestaña**.

```javascript
// Guardar (Convertir a String primero)
const config = { theme: 'dark' };
localStorage.setItem('userConfig', JSON.stringify(config));

// Leer (Parsear de vuelta)
const saved = JSON.parse(localStorage.getItem('userConfig'));

// Borrar
localStorage.removeItem('userConfig');
localStorage.clear(); // Borra TODO (Cuidado)
```

### 8.2 Cookies (La vieja escuela)
Se envían automáticamente al servidor en cada petición.
*   **Uso:** Tokens de autenticación (`HttpOnly`).
*   **Manipulación:** Es horrible en JS nativo (`document.cookie = "..."`). Usa librerías como `js-cookie`.

## 9. Fetch API (Conectando con el Mundo)

AJAX murió. Viva Fetch.

### 9.1 GET Request (Lectura)
```javascript
async function cargarUsuario() {
    try {
        const response = await fetch('https://api.github.com/users/google');
        
        if (!response.ok) throw new Error("Error 404/500");
        
        const data = await response.json(); // Leemos el body como JSON
        console.log(data.login);
    } catch (error) {
        console.error("Fallo de red:", error);
    }
}
```

### 9.2 POST Request (Escritura)
Enviar datos requiere más configuración.
```javascript
await fetch('/api/login', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json' // Importante para que el back entienda
    },
    body: JSON.stringify({ email: 'test@test.com' })
});
```

## 10. Programación Orientada a Objetos (POO)

Aunque uses React, entender Clases es vital para saber cómo funciona JS por dentro.

### 10.1 Syntactic Sugar (`class`)
Antes usábamos funciones y prototipos manualmente. Ahora:
```javascript
class Animal {
    constructor(nombre) {
        this.nombre = nombre;
    }
    
    hablar() {
        console.log(`${this.nombre} hace ruido.`);
    }
}

class Perro extends Animal {
    hablar() {
        super.hablar(); // Llama al padre
        console.log("Guau!");
    }
}

const firulais = new Perro("Firulais");
firulais.hablar(); // "Firulais hace ruido. Guau!"
```
*   **Secreto:** `typeof Animal` sigue siendo `'function'`. Es azúcar sobre Prototipos.

### 10.2 Campos Privados (ECMAScript 2022)
Usando `#` al inicio.
```javascript
class CuentaBancaria {
    #saldo = 0; // Privado real

    depositar(cantidad) {
        this.#saldo += cantidad;
    }
    
    // No puedes acceder a banco.#saldo desde fuera
}
```

## 11. El BOM (Browser Object Model)

El DOM es la página (`document`). El BOM es el navegador (`window`).

### 11.1 `navigator` (Información del Cliente)
¿Quién es el usuario?
```javascript
// Hardware
console.log(navigator.userAgent); // Tipo de navegador
console.log(navigator.language); // "es-MX"
console.log(navigator.onLine); // true/false (¿Tiene internet?)
console.log(navigator.clipboard); // Portapapeles API
```
*   **Geolocalización:**
    ```javascript
    navigator.geolocation.getCurrentPosition(pos => {
        console.log(pos.coords.latitude);
    });
    ```

### 11.2 `location` (La URL actual)
Controla la barra de direcciones.
```javascript
console.log(location.href); // URL completa
console.log(location.pathname); // "/ruta/actual"

// Redireccionar
location.href = "https://google.com"; // Guarda historial
location.replace("https://google.com"); // NO guarda historial (útil tras Logout)
```

### 11.3 `history` (SPA Navigation)
Manipular el historial sin recargar.
```javascript
history.pushState({ id: 1 }, "Titulo", "/nuevo-link");
history.back(); // Volver atrás
```

## 12. Manejo de Fechas y Moneda (`Intl`)

`Date` es horrible. `Intl` es la solución nativa moderna para formatear.

### 12.1 Fechas (`Intl.DateTimeFormat`)
```javascript
const fecha = new Date();
const formato = new Intl.DateTimeFormat('es-MX', {
    dateStyle: 'full',
    timeStyle: 'short'
}).format(fecha);

console.log(formato); 
// "domingo, 26 de enero de 2025, 10:30 p.m."
```

### 12.2 Monedas (`Intl.NumberFormat`)
Nunca formatees dinero a mano (`"$" + valor`). Rompe en otros países.
```javascript
const precio = 1234.56;
const pesos = new Intl.NumberFormat('es-MX', {
    style: 'currency',
    currency: 'MXN'
}).format(precio);

console.log(pesos); // "$1,234.56"
```

### 12.3 Tiempos Relativos
```javascript
const rtf = new Intl.RelativeTimeFormat('es', { numeric: 'auto' });
console.log(rtf.format(-1, 'day')); // "ayer"
console.log(rtf.format(2, 'minute')); // "dentro de 2 minutos"
```

## 13. Web Workers (Multithreading Real)

JS es Single Threaded. Si haces un cálculo pesado (procesar imagen, encriptar), la UI se congela.
Solución: Moverlo a otro hilo.

### 13.1 `worker.js` (El otro hilo)
Este archivo corre separado. No tiene acceso al DOM (`window`, `document` no existen).
```javascript
// worker.js
self.onmessage = (e) => {
    // Cálculo pesado
    let suma = 0;
    for (let i = 0; i < 1e9; i++) suma += i;
    
    // Devolver resultado
    self.postMessage(suma);
};
```

### 13.2 `main.js` (El hilo principal)
```javascript
const worker = new Worker('worker.js');

worker.postMessage('start'); // Iniciar

worker.onmessage = (e) => {
    console.log("Cálculo terminado:", e.data);
    // La UI nunca se congeló
};
```

## 14. Intersection Observer API (La Magia del Scroll)

Detectar cuando un elemento entra en la pantalla *sin* escuchar el evento `scroll` (que es lento).

### 14.1 Lazy Loading de Imágenes
Cargar imágenes solo cuando el usuario las ve.
```javascript
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            const img = entry.target;
            img.src = img.dataset.src; // Cargar imagen real
            observer.unobserve(img); // Dejar de observar
        }
    });
});

document.querySelectorAll('img.lazy').forEach(img => observer.observe(img));
```

### 14.2 Animaciones al Scrollear
```javascript
const animarEntrada = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            entry.target.classList.add('animate-fadeIn');
        }
    });
});
```

## 15. Drag and Drop API (Nativo)

Crear interfaces tipo Trello sin librerías.

### 15.1 Elementos Draggables
En el HTML: `<div draggable="true">Tarea 1</div>`

```javascript
const item = document.querySelector('[draggable]');

item.addEventListener('dragstart', (e) => {
    e.dataTransfer.setData('text/plain', e.target.id);
    e.target.classList.add('dragging');
});

item.addEventListener('dragend', (e) => {
    e.target.classList.remove('dragging');
});
```

### 15.2 Zonas para Soltar (Drop Zones)
```javascript
const zona = document.querySelector('.drop-zone');

zona.addEventListener('dragover', (e) => {
    e.preventDefault(); // OBLIGATORIO para permitir soltar
});

zona.addEventListener('drop', (e) => {
    e.preventDefault();
    const id = e.dataTransfer.getData('text');
    const draggable = document.getElementById(id);
    zona.appendChild(draggable); // Mover elemento al nuevo padre
});
```

## 16. Canvas API (Gráficos 2D)

Dibujar píxeles directamente.

### 16.1 Contexto 2D
```html
<canvas id="lienzo" width="500" height="500"></canvas>
```
```javascript
const canvas = document.getElementById('lienzo');
const ctx = canvas.getContext('2d');

// Cuadrado Rojo
ctx.fillStyle = 'red';
ctx.fillRect(10, 10, 100, 100);

// Texto
ctx.font = '30px Arial';
ctx.fillStyle = 'black';
ctx.fillText("Hola Mundo", 50, 50);
```

### 16.2 Animaciones (Game Loop)
Usar `requestAnimationFrame` en lugar de `setInterval`.
```javascript
function loop() {
    ctx.clearRect(0, 0, 500, 500); // Borrar anterior
    // Dibujar nuevo frame...
    requestAnimationFrame(loop);
}
loop();
```

## 17. Depuración de Memoria y Rendimiento

El navegador consume mucha RAM. Aprende a diagnosticar por qué.

### 17.1 Chrome DevTools: Memory Tab
1.  **Heap Snapshot:** Toma una "foto" de la memoria actual. Sirve para ver qué objetos ocupan más espacio.
2.  **Allocation instrumentation on timeline:** Graba en tiempo real quién está creando objetos.
3.  **Búsqueda de Detached Elements:** Si un elemento DOM fue borrado de la pantalla (remove) pero JS sigue teniendo referencia a él, es un Memory Leak.
    *   **Solución:** `elemento = null` cuando ya no lo uses.

### 17.2 WeakRef y FinalizationRegistry
Objetos que el Garbage Collector *sí* puede borrar aunque los tengas en variables.
```javascript
let cache = new WeakMap();

function cachearUsuario(usuario) {
    cache.set(usuario, "Datos extra");
    // Si 'usuario' deja de usarse en la app, se borra de 'cache' automáticamente.
}
```

## 18. Client-Side Security (Lo que un Senior sabe)

El backend no lo hace todo. El frontend es la primera línea de defensa.

### 18.1 Same-Origin Policy (SOP)
El navegador impide por defecto que `facebook.com` lea datos de `gmail.com`.
Solo puedes hacer peticiones a tu mismo dominio, a menos que el servidor active **CORS**.

### 18.2 CSP (Content Security Policy)
Un header HTTP que dice: *"Solo permite ejecutar scripts de mi-dominio.com"*.
Evita que un hacker inyecte `<script src="hacker.com/robo.js">`.

### 18.3 Vulnerabilidades Comunes
*   **XSS (Cross Site Scripting):** Inyectar JS en inputs.
    *   *Defensa:* Nunca uses `innerHTML` con datos de usuario. Escapa siempre los caracteres `< >`.
*   **Clickjacking:** Meter tu web en un `<iframe>` transparente para robar clicks.
    *   *Defensa:* Header `X-Frame-Options: DENY`.

## 19. El Futuro de la Web (Lo que viene)

JS ya no está solo.

### 19.1 WebAssembly (WASM)
Correr código de C++, Rust o Go en el navegador a velocidad nativa.
*   **Uso:** Figma, Photoshop Web, Edición de Video.
*   **JS:** Sigue siendo el pegamento, pero la lógica pesada va a WASM.

### 19.2 WebGPU
El reemplazo de WebGL. Acceso directo a la Tarjeta Gráfica (GPU).
*   **Potencial:** Juegos AAA en el navegador, Machine Learning (TensorFlow.js) acelerado por hardware.

### 19.3 Web Containers
Correr Node.js entero DENTRO del navegador (sin servidor).
Así funciona StackBlitz.
