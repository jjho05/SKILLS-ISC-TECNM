# 2.6 Selectores

## 1. Introducción

El selector es el francotirador de CSS.
Si apuntas mal, le das al elemento equivocado o no le das a nada.
Dominar los selectores es dominar la cascada.

---

## 2. Selectores Básicos (Nivel 1)

### 2.1 Selector Universal (`*`)
Selecciona TODO.
```css
* {
    box-sizing: border-box; /* El único uso aceptable */
}
```
*   *Performance:* Es lento si lo usas mal (ej. `.header *`).

### 2.2 Selector de Tipo (Etiqueta)
Selecciona por nombre de tag HTML.
```css
p { color: gray; }
```
*   *Especificidad:* 0-0-1.

### 2.3 Selector de Clase (`.`)
El caballo de batalla.
```css
.btn { padding: 10px; }
```
*   *Especificidad:* 0-1-0.
*   *Tip:* Puedes encadenar clases: `.btn.primary` (Selecciona elementos que tengan AMBAS).

### 2.4 Selector de ID (`#`)
El arma nuclear. Úsalo solo para anclas de JS o casos extremos.
```css
#header { background: black; }
```
*   *Especificidad:* 1-0-0.

---

## 3. Combinadores: Relaciones de Familia

Cómo seleccionar elementos basados en **dónde están**.

### 3.1 Descendiente (Espacio)
Cualquier nieto, bisnieto, etc.
```css
div p { color: blue; } 
```
*   "Todos los párrafos dentro de un div".

### 3.2 Hijo Directo (`>`)
Solo hijos inmediatos.
```css
ul > li { list-style: none; }
```
*   *Caso:* Un menú dropdown. Quieres afectar a los `li` del primer nivel, pero no a los del submenú.

### 3.3 Hermano Adyacente (`+`)
El que está **inmediatamente después**.
```css
h1 + p { font-size: 1.5rem; }
```
*   "El primer párrafo después del título (la entradilla)".

### 3.4 Hermano General (`~`)
Cualquier hermano que venga después (no necesariamente pegado).
```css
h1 ~ p { margin-bottom: 20px; }
```

---

## 4. Selectores de Atributo: El Poder Oculto

Puedes seleccionar elementos por sus atributos HTML. Es brutal para inputs y links.

### 4.1 Existencia y Valor Exacto
*   `[disabled]`: Elementos que tengan el atributo disabled.
*   `[type="text"]`: Inputs de texto.

### 4.2 Coincidencias de Cadena (Regex-like)
*   **Empieza con (`^=`):**
    ```css
    a[href^="https"] { color: green; } /* Sitios seguros */
    ```
*   **Termina con (`$=`):**
    ```css
    a[href$=".pdf"]::after { content: " (PDF)"; } /* Icono de PDF */
    ```
*   **Contiene (`*=`):**
    ```css
    img[src*="logo"] { width: 100px; }
    ```

---

## 5. Pseudo-clases Estructurales

Seleccionan elementos según su posición en la lista de hermanos.

### 5.1 `first-child` y `last-child`
```css
li:first-child { border-top: none; }
li:last-child { border-bottom: none; }
```

### 5.2 `nth-child(formula)`
La navaja suiza.
*   `tr:nth-child(odd)`: Filas impares (Zebra striping).
*   `tr:nth-child(even)`: Filas pares.
*   `li:nth-child(3)`: El tercero.
*   `li:nth-child(3n)`: Cada 3 elementos (3, 6, 9...).

### 5.3 `not(selector)`
La negación.
```css
button:not(.disabled) { cursor: pointer; }
```
*   *Nota:* `:not()` no aumenta la especificidad, pero su argumento sí.

---

## 6. Pseudo-clases de Estado (User Action)

*   `:hover`: Ratón encima. (Cuidado en móviles, se queda "pegado").
*   `:active`: Mientras haces clic (mousedown).
*   `:focus`: Cuando tiene el foco (teclado/clic).
*   `:visited`: Enlace ya visitado. (Muy limitado por privacidad, solo puedes cambiar color).

---

## 7. Pseudo-elementos: Creando Estructura Fantasma

Elementos que no existen en el HTML, pero CSS los crea. Llevan doble dos puntos (`::`).

### 7.1 `::before` y `::after`
Inyectan contenido antes/después del contenido del elemento.
**Requisito:** `content: ""`.
```css
blockquote::before {
    content: "“";
    font-size: 5rem;
    color: gray;
}
```

### 7.2 `::first-letter` y `::first-line`
Efectos de revista (Letra capital).
```css
p::first-letter {
    font-size: 3rem;
    float: left;
}
```

### 7.3 `::selection`
El color de fondo cuando seleccionas texto con el mouse.
```css
::selection {
    background: yellow;
    color: black;
}
```

## 8. La Matemática de la Especificidad (0-0-0)

Cuando dos reglas chocan, gana la más específica.
El navegador calcula una puntuación de 3 dígitos (A-B-C).

| Selector | Puntuación | Ejemplo |
| :--- | :--- | :--- |
| **ID** | 1-0-0 | `#header` |
| **Clase / Atributo / Pseudo-clase** | 0-1-0 | `.btn`, `[type="text"]`, `:hover` |
| **Elemento / Pseudo-elemento** | 0-0-1 | `div`, `::before` |
| **Universal / Combinadores** | 0-0-0 | `*`, `+`, `>` |
| **Inline Style** | 1-0-0-0 | `style="color: red"` (Gana a todo menos !important) |

### 8.1 Ejemplos Reales
1.  `nav#menu li.active`:
    *   1 ID (`#menu`) -> 1
    *   1 Clase (`.active`) -> 1
    *   2 Elementos (`nav`, `li`) -> 2
    *   **Total: 1-1-2**

2.  `.header .menu .item`:
    *   3 Clases -> 3
    *   **Total: 0-3-0**

**¿Quién gana?** El primero (1-1-2). Porque 1 ID vale más que 1000 clases.
*(Nota: Técnicamente en navegadores viejos 256 clases ganaban a un ID, pero eso ya no pasa).*

### 8.2 `!important`
Rompe la matemática. Gana siempre.
Solo otro `!important` con mayor especificidad puede ganarle.
**Regla:** Solo úsalo en clases de utilidad (`.d-none { display: none !important; }`) o para sobreescribir estilos inline de librerías tercas.

## 9. Selectores de Nivel 4: La Nueva Era (2022+)

Estos selectores cambian las reglas del juego. Soportados en Chrome/Firefox/Safari modernos.

### 9.1 `:is()` y `:where()`
Para agrupar y evitar repetir código.
*   **Antes:**
    ```css
    header h1, nav h1, footer h1 { ... }
    ```
*   **Ahora:**
    ```css
    :is(header, nav, footer) h1 { ... }
    ```

**Diferencia Crítica:**
*   `:is(.a, #b)`: Toma la especificidad del argumento MÁS alto (1-0-0).
*   `:where(.a, #b)`: Tiene especificidad **CERO** (0-0-0). Ideal para CSS Resets o estilos base que quieres que sean fáciles de sobreescribir.

### 9.2 `:has()` (El Selector Padre)
Por 20 años pedimos esto. "Selecciona el padre SI tiene un hijo específico".
```css
/* Selecciona la tarjeta SOLO si contiene una imagen */
.card:has(img) {
    grid-template-columns: 1fr 1fr;
}

/* Selecciona el label anterior a un input checkeado */
label:has(+ input:checked) {
    color: red;
}
```
*   *Potencia:* Te permite hacer cosas lógicas que antes requerían JS.

## 10. Performance: El Mito de "Derecha a Izquierda"

Los navegadores leen los selectores de **Derecha a Izquierda**.
Selector: `div > .btn`
1.  Navegador: "Busca todos los elementos con clase `.btn`". (Hay 50).
2.  Navegador: "De esos 50, mira si su padre directo es un `div`". (Filtrado).

Por esto:
*   `.container *`: **LENTO.** Primero busca TODOS los elementos del DOM (*), y luego verifica si están dentro de container.
*   `.btn`: **RÁPIDO.** Solo busca la clase.

*En 2025, las computadoras son tan rápidas que esto casi no importa, a menos que tengas 50,000 elementos en el DOM.*

## 11. Pseudo-clases Estructurales Avanzadas

### 11.1 `:nth-of-type`
A diferencia de `nth-child`, este solo cuenta elementos del mismo tipo.
```html
<div>
    <h1>Hola</h1> <!-- child 1 -->
    <p>Texto</p>  <!-- child 2, p:nth-of-type(1) -->
    <p>Texto</p>  <!-- child 3, p:nth-of-type(2) -->
</div>
```
*   `p:nth-child(1)`: NO selecciona nada (el hijo 1 es h1).
*   `p:nth-of-type(1)`: Selecciona el primer párrafo.

### 11.2 `:empty`
Selecciona elementos vacíos.
```css
div:empty { display: none; }
```
*   *Ojo:* Un espacio en blanco cuenta como contenido (en algunos navegadores viejos).

## 12. Laboratorio de Código: "El Selector Imposible"

Intenta resolver estos retos mentales.

**Reto 1: El Tablero de Ajedrez**
Pinta un tablero de 8x8 usando `div`s y `:nth-child`.
*   *Pista:* `nth-child(even)` no basta, porque en la siguiente fila los colores se invierten.
*   *Solución:* Matemáticas modulares o `:nth-child` con fórmulas complejas `an+b`.

**Reto 2: Estilos Condicionales sin clases**
Tienes una lista `<ul>`.
*   Si tiene menos de 3 items, píntalos rojos.
*   Si tiene más de 10, píntalos azules.
*   *Pista:* `li:first-child:nth-last-child(n+10) ~ li`. (Quantity Queries).

*   **Combinator:** Símbolo que une dos selectores (`+`, `>`, `~`).
*   **Pseudo-class:** Estado (`:hover`).
*   **Pseudo-element:** Parte lógica (`::before`).

## 14. El Axioma del Búho Lobotomizado (`* + *`)

Inventado por Heydon Pickering.
```css
* + * {
    margin-top: 1.5em;
}
```
*   **¿Qué hace?** Selecciona cualquier elemento que tenga un hermano antes. (O sea, **todos menos el primero**).
*   **¿Por qué es genio?**
    *   Le da margen superior a todos los párrafos, pero NO al primero del contenedor.
    *   No necesitas `:last-child { margin-bottom: 0 }`.
    *   Mantienes el ritmo vertical perfecto automáticamente.

## 15. Recetario de `nth-child` (Copia y Pega)

Dominar `an + b` te hace un mago.

| Fórmula | Selección | Explicación |
| :--- | :--- | :--- |
| `:nth-child(3)` | El 3 | Solo el tercer hijo. |
| `:nth-child(n+4)` | Del 4 en adelante | Selecciona 4, 5, 6... (Ignora los primeros 3). |
| `:nth-child(-n+3)` | Los primeros 3 | Selecciona 1, 2, 3. (Matemática: -0+3=3, -1+3=2, -2+3=1). |
| `:nth-child(3n)` | Múltiplos de 3 | 3, 6, 9, 12... |
| `:nth-child(odd)` | Impares | 1, 3, 5... (Zebra Striping). |
| `:nth-child(even)` | Pares | 2, 4, 6... |
| `:nth-last-child(1)` | El último | Igual a `:last-child`. |
| `:nth-last-child(2)` | El penúltimo | Cuenta desde el final. |

### 15.1 Quantity Queries
"Estila esto SOLO si hay 5 elementos o menos".
```css
/* Si hay 5 o menos hijos, píntalos a todos de verde */
li:first-child:nth-last-child(-n+5),
li:first-child:nth-last-child(-n+5) ~ li {
    color: green;
}
```

## 16. Selectores de Interacción Avanzada

Más allá de `:hover`.

### 16.1 `:focus-within` (El Salvador de los Dropdowns)
Selecciona un elemento si **él o alguno de sus hijos** tiene el foco.
*   *Caso de uso:* Un formulario que brilla entero cuando escribes en un input.
    ```css
    form:focus-within {
        box-shadow: 0 0 10px blue;
    }
    ```
*   *Caso de uso 2:* Dropdowns accesibles sin JS.

### 16.2 `:target` (Modales sin JS)
Selecciona el elemento cuyo ID coincide con la URL (`#modal1`).
```css
.modal { display: none; }
.modal:target { display: block; }
```
URL: `misitio.com/#modal1` -> El modal se abre.

### 16.3 `:indeterminate`
Para checkboxes que no están ni checked ni unchecked (estado "hijo parcial").
```css
input:indeterminate {
    background-color: gray;
}
```
Solo activable vía JS (`checkbox.indeterminate = true`).

## 17. Selectores de Internacionalización

La web es mundial. CSS te ayuda.

### 17.1 `:lang()`
Estilos específicos por idioma.
```css
/* Las comillas en francés son diferentes */
:lang(fr) q { quotes: '«' '»'; }
```

### 17.2 `:dir()` (Directionality)
Para idiomas de derecha a izquierda (RTL) como Árabe o Hebreo.
```css
/* Si el texto va de derecha a izquierda, el margen va a la izquierda */
:dir(rtl) .icon { margin-left: 10px; margin-right: 0; }
```
*   *Nota:* Es mejor usar Propiedades Lógicas (`margin-inline-start`) hoy en día.

## 18. Selectores de Validación y UX (Nivel Experto)

Mejora la experiencia del usuario sin JS.

### 18.1 `:placeholder-shown` (El detector de campo vacío)
Detecta si el usuario ha escrito algo o no.
```css
/* Si se muestra el placeholder, es que está vacío */
input:placeholder-shown { border-color: gray; }
input:not(:placeholder-shown) { border-color: blue; }
```

### 18.2 `:focus-visible` (El anillo de la accesibilidad)
El navegador pone un anillo azul feo (`outline`) al hacer clic.
Muchos devs lo quitan (`outline: none`). **ERROR GRAVE.**
Los usuarios de teclado lo necesitan.
*   **Solución:**
    ```css
    /* Solo muéstralo si usa teclado o es necesario */
    button:focus-visible {
        outline: 3px solid hotpink;
        outline-offset: 2px;
    }
    button:focus:not(:focus-visible) {
        outline: none; /* Mouse users don't see it */
    }
    ```

### 18.3 `:user-invalid` (El futuro)
`:invalid` marca el error *inmediatamente* (molesto).
`:user-invalid` marca el error solo *después* de que el usuario interactuó. (Soporte limitado aún, pero llegará).

## 19. Hackeando la Especificidad

A veces necesitas ganar, a veces necesitas perder.

### 19.1 `:where()` (La nulificadora)
Reduce la especificidad a CERO (0-0-0).
```css
/* .btn tiene especificidad 0-1-0 */
:where(.btn) { color: red; } 

/* .card tiene especificidad 0-1-0 y GANA, aunque esté arriba */
.card { color: blue; }
```
*   *Uso:* Ideal para CSS Resets o Librerías base.

### 19.2 `@layer` (Capas de Cascada)
Olvídate de calcular números. Organiza por capas.
```css
@layer base, components, utility;

@layer base {
    h1 { color: red !important; } /* Gana dentro de su capa, pero... */
}

@layer utility {
    h1 { color: blue; } /* ...las capas posteriores ganan SIEMPRE. */
}
```
*   **Resultado:** Azul. `@layer utility` gana a `@layer base` sin importar la especificidad interna.

## 20. Performance y el Render Tree

¿Importa qué selector uso?

### 20.1 El Mito del Selector Universal
`* { box-sizing: border-box; }`
Antiguamente decían que era lento.
Hoy (2025): **Despreciable.** Úsalo con confianza.

### 20.2 Descendientes Profundos
`.header .nav ul li a span`
*   El navegador lee de derecha a izquierda: "Busca todos los span... y mira si están dentro de un a... dentro de un li...".
*   **Problema:** Costoso si el DOM cambia mucho.
*   **Solución:** Usa clases directas: `.nav-text`. (BEM te obliga a esto por diseño).

### 20.3 Selectores de Atributo caros
`[href*="cadena"]` (Substring matching).
Es más lento que una clase idéntica (`.link-pdf`), pero solo importa si tienes miles de ellos.

## 21. Los Anti-Patrones: Lo que NUNCA debes hacer

### 21.1 ID para Estilos
```css
/* MAL */
#header { background: black; }
```
*   **Por qué:** Su especificidad es demasiado alta (1-0-0). Si quieres cambiar el color en una landing page específica, tendrás que usar `!important` o repetir el ID.
*   **Alternativa:** Usa clases (`.header`). Deja los IDs para JS y anclas.

### 21.2 Selectores "Trenzados"
```css
/* MAL */
div.container > ul.menu li a.link span { ... }
```
*   **Por qué:** Esto "ata" tus estilos a la estructura HTML exacta. Si cambias el `span` por un `i`, se rompe.
*   **Alternativa:** `.menu-icon { ... }`.

### 21.3 `!important` perezoso
```css
.btn { color: red !important; }
```
*   **Por qué:** Ahora no hay forma de tener un botón azul sin usar otro `!important`. Es una carrera armamentista nuclear.

## 22. Selectores Lógicos y de Medios (Multimedia)

CSS4 trae selectores para video y audio.

### 22.1 Estados de Reproducción
```css
video:playing {
    border: 5px solid green;
}

video:paused {
    filter: grayscale(100%);
}
```
*   *Uso:* UI reactiva sin JS.

### 22.2 Pantalla Completa
```css
:fullscreen {
    background: black;
    color: white;
}
```

## 23. Proyecto Final: El Juego de los Selectores

Imagina una mesa (`div.table`) con platos (`plate`) y comida.
Escribe el selector para:

**Nivel 1:** Selecciona los platos vacíos.
*   *HTML:* `<plate></plate> <plate><apple /></plate>`
*   *Solución:* `plate:empty`

**Nivel 2:** Selecciona el pepino (`pickle`) en el plato pequeño.
*   *HTML:* `<plate id="fancy"><pickle /></plate> <plate><pickle /></plate>`
*   *Solución:* `#fancy pickle` (O mejor `.fancy pickle`).

**Nivel 3:** Selecciona el 3er plato solo si tiene una naranja.
*   *Solución:* `plate:nth-child(3):has(orange)` (Nivel Dios).

## 24. Glosario de Selectores

*   **Combinator:** Símbolo que define la relación (`>`, `+`, `~`, ` `).
*   **Descendant:** Cualquier elemento anidado, sin importar el nivel.
*   **Pseudo-class:** Estado o característica (`:hover`, `:empty`). Empieza con `:`.
*   **Pseudo-element:** Parte virtual del DOM (`::before`, `::placeholder`). Empieza con `::`.
*   **Specificity:** Peso matemático de un selector (ID > Clase > Tag).
*   **Wildcard:** El asterisco (`*`).

## 25. Ejercicio Mental: ¿De qué color es el `h1`?

Resuelve esto sin mirar la respuesta.

```css
/* A */
#header h1 { color: red; } 

/* B */
html body header h1 { color: blue; }

/* C */
.title { color: green !important; }

/* D */
h1 { color: purple !important; }
```

**Análisis:**
*   A: 1-0-1 (ID + Tag).
*   B: 0-0-4 (4 Tags). (Muy baja).
*   C: 0-1-0 + `!important`.
*   D: 0-0-1 + `!important`.

**Respuesta:** **Verde (C).**
Aunque D tiene `!important`, C tiene mayor especificidad (Clase vs Etiqueta) Y `!important`.
A y B pierden contra los `!important`.
