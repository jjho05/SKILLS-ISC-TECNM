# 2.7 El Modelo de Caja: Todo es un Rectángulo

## 1. Intro: La Física de CSS

En CSS, no importa si ves un círculo, un triángulo o un texto. Para el motor de renderizado, **TODO es una caja rectangular**.
Comprender cómo se calcula el tamaño de esa caja es el 50% de CSS.

---

## 2. Anatomía de la Caja (Box Model)

Desde el centro hacia afuera:

1.  **Content (Contenido):** Texto, imagen, video. Su tamaño se define con `width` y `height`.
2.  **Padding (Relleno):** Espacio **transparente** entre el contenido y el borde.
    *   *Nota:* El background del elemento SÍ se pinta en el padding.
3.  **Border (Borde):** Línea que rodea el padding y contenido.
4.  **Margin (Margen):** Espacio **transparente** fuera del borde. Separa este elemento de sus vecinos.
    *   *Nota:* El background NO se pinta en el margen.

---

## 3. El Gran Cisma: `box-sizing`

Este es el concepto más importante de esta unidad.

### 3.1 `content-box` (El Default Malvado)
Si tienes:
```css
.caja {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
}
```
¿Cuánto mide de ancho total la caja en la pantalla?
*   Mate: 200 (width) + 20 (padding-left) + 20 (padding-right) + 5 (border-left) + 5 (border-right)
*   **Total Real:** 250px.

Esto rompe los layouts. Si querías que ocupara el 50% de la pantalla, ahora ocupa 50% + 50px, y se rompe.

### 3.2 `border-box` (La Solución)
Cambia la matemática. `width` ahora es el ancho TOTAL (de borde a borde).
```css
.caja {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px;
}
```
*   Navegador: "Ok, el usuario quiere 200px TOTALES. Como hay 40px de padding y 10px de borde, el contenido medirá 150px".
*   **Total Real:** 200px.

**Regla de Oro:**
Pon esto en tu CSS global siempre:
```css
* {
    box-sizing: border-box;
}
```

## 4. Margin Collapse (El Colapso de Márgenes)

CSS tiene una regla extraña para "ayudar" a escribir texto, pero confunde en layouts.

**Regla:** Si dos elementos tienen márgenes verticales (top/bottom) adyacentes, sus márgenes **no se suman**. Se fusionan y gana el mayor.

### 4.1 Ejemplo
```css
h1 { margin-bottom: 30px; }
p { margin-top: 20px; }
```
*   Esperado: 30 + 20 = 50px de espacio.
*   Realidad: **30px**. (El 30 se "cómeme" al 20).

### 4.2 Excepciones (Cómo evitarlo)
Los márgenes NO colapsan si:
1.  Hay algo entre ellos (un borde o padding en el padre).
2.  Usas Flexbox o Grid.
3.  Usas `overflow: hidden`.

---

## 5. Propiedades de Visualización (`display`)

Controla cómo se comporta la caja en el flujo.

### 5.1 `block` (`div`, `p`, `section`)
*   Ocupa el 100% del ancho disponible.
*   Empieza en una línea nueva.
*   Respeta `width`, `height`, `margin` y `padding`.

### 5.2 `inline` (`span`, `a`, `strong`)
*   Ocupa solo lo que mide su contenido.
*   Fluye junto al texto.
*   **Limitación:** Ignora `width`, `height`, `margin-top` y `margin-bottom`.

### 5.3 `inline-block`
Lo mejor de dos mundos.
*   Fluye como texto (uno al lado del otro).
*   Pero respeta `width`, `height` y margin vertical.
*   *Uso:* Botones, iconos.

### 5.4 `none`
*   El elemento desaparece del DOM Render Tree. No ocupa espacio.
*   Diferente a `visibility: hidden` (que lo hace invisible pero sigue ocupando espacio).

---

## 6. Overflow: Cuando el contenido desborda

Si metes un texto gigante en una caja fija de 100x100px.

*   `visible` (Default): El texto se sale de la caja y mancha lo de afuera.
*   `hidden`: Corta el exceso (se pierde).
*   `scroll`: Pone barras de scroll siempre (aunque no se necesiten).
*   `auto`: Pone barras de scroll solo si se necesitan.

## 7. Fondos y Bordes Avanzados

### 7.1 Backgrounds
```css
background: red url('gato.jpg') no-repeat center center / cover;
```
*   `cover`: Escala la imagen para cubrir todo el div sin deformarse (recorta si es necesario).
*   `contain`: Escala para que se vea toda la imagen (deja huecos).

### 7.2 Border Radius
```css
border-radius: 10px; /* Esquinas redondeadas */
border-radius: 50%; /* Crea un círculo perfecto (si es cuadrado) */
```

### 7.3 Box Shadow
```css
/* x-offset | y-offset | blur | spread | color */
box-shadow: 10px 5px 5px 0px rgba(0,0,0,0.5);
```
*   *Tip:* Usa sombras sutiles para dar profundidad (Material Design).

## 8. El Contexto de Formato de Bloque (BFC)

Concepto oscuro pero vital. Es una "región aislada" donde las reglas de layout cambian.

### 8.1 ¿Para qué sirve?
1.  **Evitar el Margin Collapse:** Los márgenes de elementos dentro de un BFC no se fusionan con los de fuera.
2.  **Contener Floats:** Si un hijo tiene `float: left`, el padre colapsa su altura a 0. Crear un BFC en el padre lo obliga a crecer y envolver al hijo.

### 8.2 Cómo crear un BFC
*   `overflow: hidden` (El hack clásico).
*   `display: flow-root` (La forma moderna y correcta).
*   `display: flex` / `grid`.
*   `position: absolute`.

---

## 9. Posicionamiento: Sacando la caja del flujo

La propiedad `position` cambia las reglas de gravedad.

### 9.1 `static` (Default)
Sigue el flujo normal. Ignora `top`, `left`, `z-index`.

### 9.2 `relative`
*   Sigue ocupando su espacio original en el flujo (no deja hueco).
*   Se desplaza *visualemente* respecto a sí mismo.
*   **Superpoder:** Crea un "punto de referencia" para sus hijos absolutos.

### 9.3 `absolute`
*   Sale del flujo (deja de ocupar espacio, los demás elementos ocupan su lugar).
*   Se posiciona respecto a su **ancestro posicionado más cercano** (uno que no sea static).
*   Si no hay ancestros, se pega al `<body>`.

### 9.4 `fixed`
*   Como `absolute`, pero relativo a la **VENTANA del navegador (Viewport)**.
*   No se mueve al hacer scroll. (Ej. Navbar pegajosa, Chat Widget).

### 9.5 `sticky`
*   Híbrido. Es `relative` hasta que haces scroll y llegas a un punto, entonces se vuelve `fixed`.
*   *Requisito:* Necesita una coordenada (`top: 0`) y un padre con altura definida.

---

## 10. Z-Index y el "Stacking Context"

Si pones `z-index: 9999` y no funciona, es porque no entiendes el Stacking Context.

**Regla:** El `z-index` solo funciona en elementos con `position` (todos menos static) o hijos de Flex/Grid.
**Jerarquía:**
1.  Un hijo nunca puede estar (z-index) "detrás" del fondo de su padre si el padre creó un contexto de apilamiento.
2.  Si el Padre A tiene `z-index: 1` y el Padre B tiene `z-index: 2` -> TODOS los hijos de B estarán por encima de los hijos de A, aunque los hijos de A tengan `z-index: 999999`.

## 11. Layout Moderno: Flexbox (1D)

Diseñado para distribuir elementos en **una sola dirección** (fila o columna).

```css
.contenedor {
    display: flex;
    justify-content: center; /* Eje Principal (X) */
    align-items: center;     /* Eje Secundario (Y) */
    gap: 10px;               /* Espacio entre hijos */
}
```
*   **Ejes:** Al cambiar `flex-direction: column`, `justify-content` ahora controla el eje Y.
*   **Flex Grow:** `flex: 1` hace que el hijo crezca para ocupar el espacio sobrante.

---

## 12. Layout Moderno: CSS Grid (2D)

Diseñado para hacer cuadrículas completas (filas Y columnas a la vez).

```css
.grilla {
    display: grid;
    /* 3 columnas: 1ra fija, 2da flexible, 3ra auto */
    grid-template-columns: 200px 1fr auto; 
    gap: 20px;
}
```
*   **fr (Fraction):** Unidad de espacio disponible. `1fr` = una parte del espacio libre.
*   **Areas:** ASCII Art en CSS.
    ```css
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    ```

## 13. Laboratorio de Código: El Centrado Perfecto

Pregunta de entrevista de Google: "¿Cómo centras un div vertical y horizontalmente?"

**Método 1: Flexbox (El Estándar)**
```css
.padre {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
}
```

**Método 2: Grid (El Hacker)**
```css
.padre {
    display: grid;
    place-items: center;
    height: 100vh;
}
```

**Método 3: Position Absolute (El Old School)**
```css
.hijo {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```

**Método 4: Auto Margin (Giga Chad)**
Solo funciona en Flex/Grid containers.
```css
.padre { display: flex; height: 100vh; }
.hijo { margin: auto; }
```

## 15. Propiedades Lógicas: El fin de `left` y `right`

En la web internacional, "Izquierda" no siempre es el inicio. En Árabe, el inicio es la derecha.
CSS inventó propiedades lógicas que se adaptan automáticamente.

### 15.1 Mapeo Mental
*   `width` -> `inline-size` (Tamaño en el texto fluye).
*   `height` -> `block-size` (Tamaño en el bloque apilado).
*   `margin-top` -> `margin-block-start`.
*   `margin-bottom` -> `margin-block-end`.
*   `margin-left` -> `margin-inline-start` (Si es inglés es Left, si es árabe es Right).
*   `margin-right` -> `margin-inline-end`.

**Consejo 2025:** Deja de usar `margin-left`. Usa `margin-inline-start`. Tu yo del futuro te lo agradecerá cuando tengas que traducir la web.

## 16. Aspect Ratio y Multimedia

Antes para hacer un video responsive de 16:9 necesitabas un "padding hack" horrible.
Ahora:
```css
.video-container {
    width: 100%;
    aspect-ratio: 16 / 9;
    background: black;
}
```
Si el ancho cambia, la altura se calcula sola. Magia pura.

## 17. Container Queries (`@container`) - El Futuro

Las Media Queries (`@media (max-width: 600px)`) tienen un fallo fatal: miran la pantalla entera.
Pero un componente (ej. una tarjeta de producto) puede estar en una sidebar estrecha o en el contenido principal ancho.
La tarjeta debería reaccionar a **su contenedor**, no a la pantalla.

### 17.1 Sintaxis
1.  **Definir el contenedor:**
    ```css
    .sidebar {
        container-type: inline-size; /* Vigila mi ancho */
        container-name: sidebar;     /* Opcional */
    }
    ```

2.  **Usar la query:**
    ```css
    @container (min-width: 400px) {
        /* Si el contenedor de la tarjeta mide más de 400px... */
        .card {
            display: flex; /* ...pon la imagen al lado del texto */
        }
    }
    ```

**Impacto:** Esto permite crear componentes verdaderamente "agnósticos" que funcionan bien donde sea que los tires.

## 18. Funciones Matemáticas (`calc`, `clamp`)

CSS tiene calculadora integrada.

### 18.1 `calc()`
Mezcla unidades.
```css
/* El ancho total menos 50px de margen */
width: calc(100% - 50px); 
```

### 18.2 `clamp(min, val, max)`
La función definitiva para tipografía fluida.
```css
/* 
   - Nunca menos de 1rem.
   - Idealmente 5% del ancho de pantalla (5vw).
   - Nunca más de 2rem.
*/
font-size: clamp(1rem, 5vw, 2rem);
```
Adiós a escribir 50 media queries para tamaños de fuente.

## 19. Grid Layout a Fondo: Pintando con ASCII

`grid-template-areas` es la característica más subestimada de CSS. Te permite visualizar tu layout en el código.

### 19.1 Ejemplo Complejo
```css
.layout {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    gap: 20px;
    grid-template-areas:
        "header header header"
        "sidebar content ads"
        "footer footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.ads { grid-area: ads; }
.footer { grid-area: footer; }
```
*   **Media Query:** Para hacer esto responsive, solo redefines las áreas en el media query.
    ```css
    @media (max-width: 600px) {
        .layout {
            grid-template-columns: 1fr;
            grid-template-areas:
                "header"
                "content"
                "sidebar"
                "ads"
                "footer";
        }
    }
    ```
    ¡Sin tocar márgenes ni floats! Solo reordenas las strings.

## 20. Subgrid (Grid 2.0)

El problema de Grid nivel 1 es que los nietos no pueden alinearse con la grilla del abuelo.
`subgrid` soluciona esto.

### 20.1 El Problema
Tienes una tarjeta dentro de una grilla. La tarjeta tiene título, texto y pie.
Quieres que el pie de TODAS las tarjetas esté alineado, aunque unas tengan más texto que otras.

### 20.2 La Solución
```css
.grid-padre {
    display: grid;
    grid-template-rows: auto 1fr auto; /* Título, Contenido, Pie */
}

.tarjeta {
    grid-row: span 3; /* Ocupa 3 filas del padre */
    display: grid;
    grid-template-rows: subgrid; /* Hereda las filas del abuelo */
}
```
Ahora el contenido de la tarjeta dicta el tamaño de la fila de LA GRILLA EXTERNA. Alineación perfecta mágica.

## 21. Frameworks de Layout: ¿Siguen siendo necesarios?

Hace 10 años, necesitábamos Bootstrap Grid System (`.col-md-4`) porque no existía Grid nativo.

| Método | HTML | CSS | Flexibilidad |
| :--- | :--- | :--- | :--- |
| **Bootstrap Grid** | Sucio (`<div class="row"><div class="col-4">`) | Pesado (Librería externa) | Limitada a 12 columnas. |
| **Grid Nativo** | Limpio (`<div class="gallery">`) | Ligero (`display: grid`) | Infinita (N columnas). |

**Veredicto 2025:**
No uses el sistema de Grid de Bootstrap A MENOS que sea un proyecto legacy.
Abrende CSS Grid nativo. Es más potente, más limpio y estándar.

## 22. Funciones CSS Nivel Dios

Deja de usar píxeles fijos. Usa matemática.

### 22.1 `min()` y `max()`
*   `width: min(500px, 100%)`: Elige el valor MENOR.
    *   Si la pantalla es gigante, usa 500px.
    *   Si es un móvil de 300px, usa 100% (300px).
    *   **Resultado:** Responsive automático sin media queries.

### 22.2 `minmax(min, max)`
Exclusivo de Grid.
```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```
*   "Crea tantas columnas como quepan. Cada una debe medir AL MENOS 250px, pero si sobra espacio, estírate (`1fr`)".
*   Este es el **Pattern RAM (Repeat, Auto, Minmax)**. El layout más útil de la historia.

### 22.3 `fit-content(value)`
"Crece según tu contenido, pero no te pases de X píxeles".

## 23. Proyecto Final: Layout "Intrinsic" (Sin Media Queries)

El santo grial del diseño web moderno es no usar `@media`.

```css
.holy-grail {
    display: grid;
    height: 100vh;
    /* 
       Sidebar: 250px fija
       Content: El resto
    */
    grid-template-columns: 250px 1fr;
    grid-template-rows: auto 1fr auto;
    gap: var(--gap);
}

/* Responsividad Mágica */
/* Si el ancho es menor a 600px, la sidebar desaparece o se mueve */
.sidebar {
    display: none; /* Simplificado para el ejemplo */
}

/* El verdadero truco intrinsic para galerías */
.gallery {
    display: grid;
    /* Esto crea columnas responsive automáticas */
    grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
    gap: 1rem;
}
```

### 23.1 El Futuro: Masonry
Grid nivel 3 traerá soporte nativo para Masonry (tipo Pinterest).
```css
.pinterest {
    display: grid;
    grid-template-rows: masonry; /* Aún experimental en 2025 */
}
```

## 24. Glosario de Layout Avanzado

*   **Fraction (`fr`):** Unidad de distribución de espacio libre. NO es porcentaje.
*   **Implicit Grid:** Filas/Columnas que el navegador crea automáticamente cuando metes más contenido del que definiste.
*   **Gutters:** El espacio entre celdas (`gap`).
*   **Intrinsic Sizing:** Dejar que el contenido defina el tamaño (`max-content`).
*   **Extrinsic Sizing:** Forzar un tamaño fijo (`width: 500px`).

## 25. Debugging de Layouts: Herramientas

No adivines. Inspecciona.

### 25.1 Inspector de Grid y Flex
En Chrome/Firefox DevTools, al lado de `<div display="grid">` aparece una etiqueta `grid`.
*   **Clickeala:** Dibuja las líneas de la grilla en la pantalla.
*   **Clickea `flex`:** Muestra el espacio libre y cómo se distribuyen los items.

### 25.2 "Computed" Tab
A veces escribes `width: 50%` pero no sabes cuánto es.
Ve a la pestaña **Computed**. Te dirá: `width: 384.5px`.
Ahí también verás si alguna otra regla está sobreescribiendo tu estilo (tachado).

## 26. Errores Clásicos de Novato

### 26.1 "El `z-index` no funciona"
*   **Causa:** El elemento es `position: static` (por defecto).
*   **Solución:** Ponle `position: relative`.

### 26.2 "El margen no empuja"
*   **Causa:** Margin Collapse o el elemento es `display: inline` (`<span>`).
*   **Solución:** Hazlo `display: block` o `inline-block`.

### 26.3 "Aparece un scroll horizontal fantasma"
*   **Causa:** Algún elemento mide `100vw` pero ignoraste la barra de scroll vertical (que ocupa ~15px). O usaste `width: 100% + padding` sin `border-box`.
*   **Solución:** `outline: 1px solid red` a todo (`*`) para encontrar al culpable que se sale del layout.

## 27. Layout Multi-Columna (Tipo Periódico)

Un módulo olvidado de CSS que es increíble para texto largo.
No es Flexbox, no es Grid. Son columnas de texto reales.

```css
.article {
    column-count: 3; /* Divide el texto en 3 columnas */
    column-gap: 2rem; /* Espacio entre ellas */
    column-rule: 1px solid gray; /* Línea divisoria */
}

h2 {
    column-span: all; /* El título rompe las columnas y ocupa todo el ancho */
}
```
*   **Magia:** El texto fluye de la columna 1 a la 2 automáticamente.

## 28. `display: contents` (El Fantasma)

A veces tienes un `div` que solo estorba para el Grid/Flexbox, pero lo necesitas para semántica o React.

```html
<div class="grid">
    <div class="wrapper"> <!-- Este div rompe el grid -->
        <div class="item">Item</div>
    </div>
</div>
```

**Solución:**
```css
.wrapper {
    display: contents;
}
```
*   **Efecto:** El navegador "borra" la caja del `.wrapper` visualmente.
*   Sus hijos (`.item`) se comportan como s fueran hijos directos de `.grid`.
*   El `.wrapper` sigue existiendo en el DOM, pero no genera `box` ni padding ni margin.
