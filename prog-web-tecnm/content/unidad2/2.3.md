# 2.3 Elementos Básicos: Los Ladrillos de la Web

## 1. Introducción

Si el `<head>` es el cerebro, el `<body>` es el cuerpo. Y ese cuerpo está hecho de átomos básicos.
En esta unidad estudiaremos los elementos que componen el 90% de la web visible.

---

## 2. Texto y Semántica: Más allá del `<p>`

En los 90s, todo era `<b>` y `<i>`. Hoy, usamos semántica.

### 2.1 Párrafos y Títulos
*   **`<h1>` a `<h6>`:** Jerarquía. Solo debe haber UN `<h1>` por página (el título principal).
    *   *SEO:* Google castiga si saltas de `h2` a `h4`.
*   **`<p>`:** Párrafo de texto. Desplaza hacia abajo a otros bloques.

### 2.2 Énfasis Semántico
*   **`<em>` (Emphasis):** Cursiva visualmente, pero significa "cambio de tono".
    *   "No *hagas* eso" (Suena diferente).
*   **`<strong>` (Strong Importance):** Negrita visualmente, significa "Urguencia/Seriedad".
    *   "**Peligro:** No tocar".
*   **`<mark>`:** Resaltado (como un marcatextos amarillo). Útil para resultados de búsqueda.

### 2.3 Citas y Definiciones
*   **`<blockquote>`:** Cita en bloque larga.
*   **`<q>`:** Cita corta en línea (pone comillas automáticas).
*   **`<cite>`:** Título de la obra citada.
*   **`<abbr title="World Health Organization">WHO</abbr>`:** Abreviaturas.

### 2.4 Código y Preformateado
*   **`<code>`:** Código fuente (fuente monoespaciada).
*   **`<pre>`:** Respeta los espacios y saltos de línea (ASCII Art).
    *   *Truco:* `<pre><code>...</code></pre>` es el estándar para bloques de código.

## 3. Hipervínculos: La `<a>` de Áncora

El elemento que inventó la web.

### 3.1 Anatomía
`<a href="https://google.com" target="_blank" rel="noopener">Ir a Google</a>`

*   **`href` (Hypertext Reference):** ¿A dónde voy?
    *   Absoluta: `https://...`
    *   Relativa: `/contacto`
    *   Ancla: `#footer` (scrollea al elemento con id="footer").
    *   Protocolos raros: `mailto:`, `tel:`, `sms:`.

### 3.2 Seguridad (`target="_blank"`)
Si abres una pestaña nueva (`target="_blank"`), la página nueva puede acceder a tu ventana original usando `window.opener` y redirigirla a un sitio de phishing.
**Solución:** Siempre usa `rel="noopener noreferrer"`. (Los navegadores modernos ya lo hacen por defecto, pero es buena práctica).

## 4. Listas: Ordenando el Caos

### 4.1 No Ordenadas (`<ul>`)
Bullets points.
*   Uso real: Menús de navegación (`<nav><ul><li>...`).
*   Estilos: `list-style-type: none` (para quitar puntitos).

### 4.2 Ordenadas (`<ol>`)
Números (1, 2, 3) o letras (A, B, C).
*   Atributos chidos:
    *   `start="5"`: Empezar en 5.
    *   `reversed`: Cuenta regresiva (10, 9, 8...).

### 4.3 De Definición (`<dl>`)
La gran olvidada. Perfecta para glosarios o metadatos key-value.
```html
<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado.</dd>
    <dt>CSS</dt>
    <dd>Lenguaje de estilos.</dd>
</dl>
```

## 5. Tablas: Solo para Datos, NO para Layout

En 1999, usábamos tablas para diseñar webs completas. Hoy es pecado mortal (problemas de accesibilidad y responsive).
Úsalas solo para Excel-like data.

### 5.1 Estructura Completa
```html
<table>
    <caption>Reporte de Ventas</caption>
    <thead>
        <tr>
            <th>Producto</th>
            <th>Precio</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Manzanas</td>
            <td>$10</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>Total</td>
            <td>$10</td>
        </tr>
    </tfoot>
</table>
```

### 5.2 Fusión de Celdas
*   **`colspan="2"`:** Ocupa 2 columnas.
*   **`rowspan="2"`:** Ocupa 2 filas.

## 6. Multimedia: Imagen, Video y Audio

### 6.1 Imágenes (`<img>`)
*   **`alt`:** OBLIGATORIO. Texto alternativo para ciegos o si falla la carga.
*   **`loading="lazy"`:** Carga diferida nativa. La imagen no descarga hasta que el usuario hace scroll cerca de ella. (Mejora brutal del performance).

### 6.2 Imágenes Responsivas (`<picture>`)
Sirve una imagen pequeña a celulares y una gigante a 4K.
```html
<picture>
    <source media="(max-width: 600px)" srcset="foto-movil.jpg">
    <source media="(min-width: 601px)" srcset="foto-desktop.jpg">
    <img src="fallback.jpg" alt="Foto adaptable">
</picture>
```

### 6.3 Video y Audio
HTML5 mató a Flash con estas etiquetas.
```html
<video controls poster="miniatura.jpg" width="500">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm"> <!-- Google Format -->
    Tu navegador es prehistórico.
</video>
```

## 7. Objetos Embebidos

### 7.1 `<iframe>`
Una ventana a otra web.
*   Uso: Mapas de Google, Videos de YouTube.
*   Seguridad: `sandbox` (restringe lo que el iframe puede hacer, como ejecutar JS).

### 7.2 `<object>` y `<embed>`
Reliquias para cargar PDFs o (antes) Flash/Java Applets.
Hoy en día se usan poco, excepto para PDFs.

---

## 8. Semántica Estructural: Organizando el Contenido

No todo es `<div>`. HTML5 introdujo etiquetas para describir *qué* es cada parte de la página.

### 8.1 `<main>`
*   El contenido principal y único de la página.
*   **Regla:** Solo puede haber UNO visible por página.
*   No lo anides dentro de un `<footer>` o `<nav>`.

### 8.2 `<article>` vs `<section>` (La confusión eterna)
*   **`<article>`:** Contenido independiente que tiene sentido por sí mismo (ej. Un post de blog, un tweet, una noticia). Si lo sacas de la web y lo pones en un RSS, ¿se entiende? Sí -> Usa Article.
*   **`<section>`:** Una agrupación temática de contenido. Generalmente tiene un título (`h2`). Ej. "Sección de Comentarios", "Sección de Biografía".
*   *Veredicto:* Si no sabes cuál usar, usa `<div>`. No abuses de la semántica.

### 8.3 `<aside>`
Contenido tangencial (relacionado levemente).
*   Barra lateral (Sidebar).
*   Caja de "Artículos relacionados".
*   Publicidad.

### 8.4 `<nav>`, `<header>`, `<footer>`
*   **`<nav>`:** Bloques de navegación PRINCIPALES. (No uses `<nav>` para 3 links en el footer).
*   **`<header>`:** Cabecera introductoria (Logo + Menú + H1). Puede haber varios (uno por `<article>`).
*   **`<footer>`:** Pie de página (Copyright, Autor). También puede haber varios (pie del artículo).

## 9. Interactividad Nativa (Sin JavaScript)

HTML moderno trae widgets que antes requerían jQuery.

### 9.1 `<details>` y `<summary>` (Acordeón)
Crea una sección colapsable nativa.
```html
<details>
    <summary>Más información...</summary>
    <p>Aquí está el texto oculto que se revela al hacer clic.</p>
</details>
```
*   *Ventaja:* 100% accesible y funciona sin JS.

### 9.2 `<dialog>` (Modales/Popups)
Nuevo estándar (2022/2023). Adiós a los líos de `z-index`.
```html
<dialog id="miModal">
    <p>¡Soy una ventana modal nativa!</p>
    <form method="dialog">
        <button>Cerrar</button>
    </form>
</dialog>
```
*   **JS necesario:** `document.getElementById('miModal').showModal()`.
*   **Feature:** Automáticamente crea un "backdrop" (fondo oscuro) y bloquea el resto de la página (Focus Trap) para accesibilidad.

## 10. Multimedia Avanzado: Subtítulos (`<track>`)

Haz tu web accesible para sordos.
```html
<video controls>
    <source src="batman.mp4" type="video/mp4">
    <track kind="subtitles" src="batman_es.vtt" srclang="es" label="Español">
    <track kind="captions" src="batman_cc.vtt" srclang="es" label="Español (CC)">
</video>
```
*   **Subtitles:** Traducción del diálogo.
*   **Captions:** Diálogo + Sonidos ("Suena explosión", "Música de tensión").

## 11. Enlaces Avanzados

### 11.1 Descarga Forzada (`download`)
`<a href="imagen.jpg" download="vacaciones.jpg">Descargar</a>`
*   Fuerza al navegador a "Guardar como..." en lugar de abrir la imagen.
*   Puedes cambiar el nombre del archivo con el atributo.

### 11.2 El Atributo `ping` (Analytics)
`<a href="https://tienda.com" ping="/track/click">Comprar</a>`
*   Cuando el usuario hace clic, el navegador envía una petición POST silenciosa a `/track/click`.
*   *Uso:* Trackear clics sin usar JS síncrono ni redirecciones lentas.

## 12. Laboratorio de Código: Componente Tarjeta Semántica (Card)

Vamos a crear una "Card" de producto accesible y semántica.

```html
<article class="card">
    <figure>
        <img src="tenis.jpg" alt="Tenis Nike Air Jordan rojos" loading="lazy">
        <figcaption>Modelo 2024</figcaption>
    </figure>
    
    <div class="card-body">
        <h2>Nike Air Jordan</h2>
        <p class="precio">
            <span class="visually-hidden">Precio actual:</span>
            <strong>$120.00</strong>
            <del aria-label="Precio original">$150.00</del>
        </p>
        <p>Los mejores tenis para <em>saltar</em> alto.</p>
        
        <a href="/buy" class="btn">Comprar Ahora</a>
    </div>
</article>
```
*   **`<article>`:** Porque la tarjeta es contenido independiente.
*   **`<figure>`:** Para agrupar imagen y leyenda.
*   **`visually-hidden`:** Clase CSS para esconder texto que solo queremos que lean los ciegos ("Precio actual").
*   **`<del>`:** Texto tachado (semánticamente "borrado" o antiguo).

## 14. Glosario de Elementos

*   **Anchor (`<a>`):** Ancla. Conecta dos recursos.
*   **Blockquote:** Cita en bloque. Generalmente indentada por el navegador.
*   **Empty Element (Void):** Elemento sin contenido ni cierre (`<img>`, `<br>`, `<hr>`).
*   **Fallback:** Contenido de respaldo que se muestra si la opción principal falla (ej. texto dentro de `<video>`).
*   **Semantic Web:** La idea de que el HTML debe describir el significado, no la apariencia.
*   **VTT (Web Video Text Tracks):** Formato estándar para subtítulos.

## 15. Elementos Oscuros pero Útiles

Etiquetas que el 90% de los devs olvidan, pero que te hacen ver como un experto.

### 15.1 Medidores y Progreso
*   **`<progress value="70" max="100">`:** Barra de progreso semántica (Descarga al 70%).
*   **`<meter value="2" min="0" max="10">`:** Medidor de disco, batería o votos (2/10).
    *   *Diferencia:* Progress es para tareas que acaban. Meter es para valores estáticos.

### 15.2 Datos y Variables
*   **`<time datetime="2024-12-25">Navidad</time>`:** Ayuda a Google Calendar a crear eventos.
*   **`<kbd>`:** "Presiona <kbd>Ctrl</kbd> + <kbd>C</kbd>".
*   **`<samp>`:** Salida de computadora.
*   **`<var>`:** Variable matemática (`<var>x</var> = <var>y</var> + 2`).
*   **`<output>`:** Resultado de un cálculo en un formulario.

## 16. Tablas Avanzadas para Accesibilidad

Una tabla sin `scope` es una pesadilla para un lector de pantalla.

```html
<table>
    <colgroup>
        <col style="background-color: #f2f2f2"> <!-- Columna 1 gris -->
        <col span="2"> <!-- Columnas 2 y 3 normales -->
    </colgroup>
    <thead>
        <tr>
            <td></td>
            <th scope="col">Lunes</th>
            <th scope="col">Martes</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">9:00 AM</th>
            <td>Matemáticas</td>
            <td>Física</td>
        </tr>
    </tbody>
</table>
```
*   **`scope="col"`:** "Este encabezado aplica a toda la columna hacia abajo".
*   **`scope="row"`:** "Este encabezado aplica a toda la fila a la derecha".
*   **`<colgroup>`:** Permite estilar columnas enteras sin poner clases en cada `<td>`.

## 17. Imágenes Responsivas: La Guía Definitiva

Hay dos formas de hacer imágenes responsive. No las confundas.

### 17.1 Density Switching (`x` descriptor)
Para pantallas Retina (iPhone, MacBook). Misma imagen, más píxeles.
`<img src="foto.jpg" srcset="foto.jpg 1x, foto-2x.jpg 2x" alt="...">`
*   Si la pantalla es 1x (Monitores viejos), baja `foto.jpg`.
*   Si es 2x (Retina), baja `foto-2x.jpg`.

### 17.2 Resolution Switching (`w` descriptor + `sizes`)
Para diferentes anchos de pantalla.
```html
<img src="small.jpg"
     srcset="small.jpg 500w, medium.jpg 1000w, large.jpg 1500w"
     sizes="(max-width: 600px) 100vw, 50vw"
     alt="...">
```
*   El navegador hace matemáticas complejas: "La pantalla mide 400px, y la imagen ocupará el 100% (400px), así que bajaré `small.jpg` (500w) porque es la que mejor calza".
*   **Magia:** El navegador elige la MEJOR imagen antes de empezar a renderizar el layout.

### 17.3 Art Direction (`<picture>`)
Cambiar la foto completamente (Corte horizontal en desktop, corte vertical en móvil).
Esto **NO** lo puedes hacer con `srcset`. Necesitas `<picture>`.

## 18. Iframes Avanzados

El elemento más peligroso y poderoso a la vez.

### 18.1 Permisos (`allow`)
Controla qué hardware puede usar el iframe.
`<iframe src="..." allow="camera; microphone; geolocation" allowfullscreen></iframe>`

### 18.2 Sandbox
Crea una jaula de seguridad.
`<iframe src="..." sandbox>` 
*   Bloquea JS, formularios, popups, cookies.
*   Para permitir cosas específicas: `sandbox="allow-scripts allow-forms"`.

### 18.3 Lazy Loading
`<iframe src="..." loading="lazy"></iframe>`
*   Igual que las imágenes. El iframe de YouTube no carga hasta que el usuario hace scroll hasta él. Ahorra megabytes de datos.

## 19. Errores Comunes de Principiante (Anti-Patrones)

1.  **Enlazar JS con `href`:** `<a href="javascript:void(0)">`.
    *   *Correcto:* Usa `<button type="button">`. Los enlaces son para navegar, los botones para acciones.
2.  **Imágenes como Texto:** Usar una imagen de un banner con texto quemado.
    *   *Problema:* No es accesible, no se traduce, pixela al hacer zoom.
    *   *Correcto:* Usa texto real sobre un fondo (`background-image`).
3.  **Divitis Aguda:** Usar `div` para todo.
    *   `<div class="titulo">` -> `<h1>`
    *   `<div class="boton">` -> `<button>`
    *   `<div class="menu">` -> `<nav>`

## 20. El Cementerio de Etiquetas (Deprecated)

No uses esto, o los seniors te mirarán mal.

### 20.1 `<marquee>` y `<blink>`
*   Inventos de los 90s para mover texto o hacerlo parpadear.
*   **Estado:** Eliminados del estándar.
*   **Reemplazo:** CSS Animations.

### 20.2 `<font>` y `<center>`
*   Mezclaban estilo con estructura.
*   **Reemplazo:** CSS (`color`, `text-align: center`).

### 20.3 `<frameset>` y `<frame>`
*   Antes de los iframes, dividíamos la ventana entera en marcos.
*   **Problema:** Rompía la navegación, el botón "Atrás" y los bookmarks.
*   **Estado:** Muerto y enterrado.

## 21. Tipografía Internacional: Ruby Annotations

Si alguna vez haces una web para Japón o China, necesitas esto. Sirve para mostrar la pronunciación (Furigana) sobre los caracteres (Kanji).

```html
<ruby>
  漢 <rp>(</rp><rt>kan</rt><rp>)</rp>
  字 <rp>(</rp><rt>ji</rt><rp>)</rp>
</ruby>
```
*   **`<rt>`:** El texto pequeño arriba.
*   **`<rp>`:** Paréntesis de fallback para navegadores que no soportan Ruby (ya casi no hay).

## 22. WAI-ARIA Roles: Cuando la semántica no basta

A veces usas un `<div>` complejo que actúa como un Tab o un Menú.

### 22.1 Landmark Roles
Ayudan a los ciegos a saltar entre secciones grandes.
*   `role="banner"` (Generalmente el `<header>`).
*   `role="navigation"` (Generalmente el `<nav>`).
*   `role="main"` (El `<main>`).
*   `role="search"` (Formulario de búsqueda).

### 22.2 Widget Roles
*   `role="tablist"`, `role="tab"`, `role="tabpanel"`.
*   `role="progressbar"`.
*   `role="slider"`.

## 22. Elementos Interactivos Nativos (Adiós JS)

HTML5.2 trajo componentes que antes requerían librerías pesadas.

### 22.1 `<dialog>`: El Modal Nativo
Olvida Bootstrap Modals. Esto es estándar.
```html
<dialog id="miModal">
    <h2>¡Hola!</h2>
    <p>Soy un modal nativo.</p>
    <form method="dialog">
        <button>Cerrar</button> 
    </form>
</dialog>

<button onclick="document.getElementById('miModal').showModal()">Abrir</button>
```
*   **Ventajas:**
    *   Gestiona el foco automáticamente (Accesibilidad gratis).
    *   Cierra con `Esc` automáticamente.
    *   Fondo `::backdrop` personalizable.
    *   `showModal()` bloquea el resto de la página. `show()` no.

### 22.2 `<details>` y `<summary>`: El Acordeón Nativo
```html
<details>
    <summary>Más información...</summary>
    <p>Aquí está el contenido oculto. Puede ser texto, imágenes, o más details.</p>
</details>
```
*   **CSS Tip:** Puedes animarlo, aunque requiere trucos de altura o la nueva API de `interpolate-size`.

## 23. Web Components: La Introducción

HTML es extensible. Puedes crear tus propias etiquetas.

### 23.1 Custom Elements
```javascript
class MiBoton extends HTMLElement {
    connectedCallback() {
        this.innerHTML = "<button>Soy un botón especial</button>";
        this.style.color = "red";
    }
}
customElements.define('mi-boton', MiBoton);
```
HTML: `<mi-boton></mi-boton>`

### 23.2 Shadow DOM
El encapsulamiento real. Los estilos de dentro NO salen, y los de fuera NO entran.
```javascript
const shadow = this.attachShadow({mode: 'open'});
shadow.innerHTML = `<style>p { color: blue; }</style> <p>Soy azul solo aqui.</p>`;
```

## 24. Microdata y Web Semántica (SEO Técnico)

Ayuda a Google a entender que tu producto vale $50 USD.

```html
<div itemscope itemtype="https://schema.org/Product">
    <h1 itemprop="name">iPhone 15</h1>
    <img src="iphone.jpg" itemprop="image" />
    <span itemprop="description">El mejor teléfono.</span>
    
    <div itemprop="offers" itemscope itemtype="https://schema.org/Offer">
        <span itemprop="priceCurrency" content="USD">$</span>
        <span itemprop="price" content="799.00">799.00</span>
        <link itemprop="availability" href="https://schema.org/InStock" />
    </div>
</div>
```
*   Esto genera las "Rich Cards" en los resultados de búsqueda de Google (estrellitas, precio, stock).

## 25. La Etiqueta `<template>` (El Clonador)

El elemento más eficiente para crear contenido dinámico con JS.

```html
<template id="mi-template">
    <div class="tarjeta">
        <h2 class="titulo"></h2>
        <p class="desc"></p>
    </div>
</template>
```

**Comportamiento Único:**
1.  El navegador **parsea** el contenido (verifica que sea HTML válido).
2.  Pero **NO lo renderiza** (no carga imágenes, no ejecuta scripts).
3.  Está "dormido" hasta que lo clonas con JS.

**Uso:**
```javascript
const template = document.getElementById('mi-template');
const clon = template.content.cloneNode(true);
clon.querySelector('.titulo').textContent = "Producto 1";
document.body.appendChild(clon);
```
