## 📖 Introducción

Bienvenido al repositorio **Skills ISC - TecNM**, un proyecto educativo que recopila y organiza una biblioteca completa de recursos de aprendizaje para todas las materias de la carrera de **Ingeniería en Sistemas Computacionales** del Tecnológico Nacional de México.

### ¿Qué es este proyecto?

Este repositorio contiene **skills educativos** (módulos de conocimiento) que están:
- ✅ **100% alineados** con los programas oficiales del TecNM
- ✅ **Libres de sesgos** mediante el uso exclusivo de fuentes oficiales
- ✅ **Enriquecidos** con teoría detallada, ejercicios resueltos y código ejecutable
- ✅ **Automatizados** para facilitar la creación de nuevas materias

Cada skill incluye:
- **README.md completo** con el programa oficial íntegro (datos generales, competencias, temario, actividades, prácticas, evaluación y bibliografía)
- **Desglose por unidades** con archivos individuales para cada tema y subtema
- **Códigos ejecutables** organizados por unidad para práctica inmediata
- **Referencias teóricas** con fórmulas, métodos y conceptos clave
- **Verificación oficial** mediante extracción directa del PDF del TecNM

### ¿Para quién es?

- **Estudiantes** que buscan material de estudio completo y estructurado
- **Docentes** que necesitan recursos didácticos alineados con el programa oficial
- **Comunidad TecNM** que busca compartir y mejorar recursos educativos

### ¿Cómo funciona?

Cada materia (skill) se crea siguiendo un proceso estandarizado:

1. **Extracción del PDF oficial** del TecNM usando `tools/pdf_reader.py`
2. **Creación del README** con el programa completo (sin omitir ninguna sección)
3. **Desglose de contenido** - cada unidad y subtema en archivos individuales
4. **Desarrollo de código** - scripts y ejemplos ejecutables por unidad
5. **Verificación de alineación** - 100% fiel al documento oficial

## 📥 Cómo Descargar una Materia Individual

Si solo te interesa una materia específica (por ejemplo, Simulación), no necesitas descargar todo este repositorio. Cada skill funciona de manera independiente.

### Opción 1: Clonar desde la terminal (Recomendado)

```bash
# Ejemplo para Simulación
git clone https://github.com/jjho05/simulacion-tecnm.git
```

### Opción 2: Descargar ZIP

1. Haz clic en el nombre de la materia en la tabla de arriba (te llevará al repositorio individual).
2. En GitHub, haz clic en el botón verde **Code**.
3. Selecciona **Download ZIP**.

## 🎯 Objetivo del Proyecto

Crear una biblioteca educativa completa y de alta calidad que:

- **Esté 100% alineada con los programas oficiales del TecNM** - Cada skill se crea directamente del PDF oficial, sin omitir ninguna sección (caracterización, intención didáctica, competencias, temario, actividades, prácticas, evaluación, bibliografía)

- **Elimine sesgos mediante el uso exclusivo de fuentes oficiales** - No se utilizan interpretaciones o contenido de terceros, solo el documento oficial del TecNM

- **Proporcione recursos prácticos** - Scripts ejecutables, ejemplos resueltos paso a paso, ejercicios propuestos y actividades de aprendizaje

- **Facilite el aprendizaje** - Estructura clara y navegable, con archivos individuales por cada subtema para estudio enfocado

- **Sea completamente automatizable y replicable** - Herramientas y metodología documentada para crear nuevas materias de forma consistente

## 📖 Estructura Estándar de Cada Skill

Cada skill sigue la estructura definida en la [Guía Maestra](GUIA_CREACION_SKILLS_TECNM.md):

```
nombre-skill/
├── README.md                 # Programa oficial completo del TecNM
│                             # Incluye: datos generales, presentación,
│                             # competencias, temario, actividades,
│                             # prácticas, evaluación y bibliografía
│
├── SKILL.md                  # Definición del skill para asistentes IA
│                             # Formato: YAML frontmatter + instrucciones
│
├── [Materia].pdf            # PDF oficial descargado del TecNM
├── pdf_extracted.txt         # Texto extraído del PDF para verificación
│
├── references/               # Material teórico de referencia
│   ├── temario-completo.md   # Temario con competencias y subtemas
│   └── formulas-metodos.md   # Fórmulas y métodos clave (si aplica)
│
├── content/                  # Desglose detallado por unidad
│   ├── unidad1/
│   │   ├── README.md         # Índice de la unidad con competencia
│   │   ├── 1.1.md            # Subtema individual con teoría
│   │   ├── 1.2.md
│   │   └── codigos/          # Ejemplos ejecutables de la unidad
│   │       └── ejemplo_u1.py
│   ├── unidad2/
│   │   ├── README.md
│   │   ├── 2.1.md
│   │   ├── 2.2.1.md          # Subsubtemas cuando aplique
│   │   └── codigos/
│   └── ...
│
└── scripts/                  # Herramientas principales (si aplica)
    ├── generador_X.py
    └── simulador_Y.py
```

## 🛠️ Herramientas del Proyecto

### PDF Reader - Extractor Automatizado

**Ubicación:** [`tools/pdf_reader.py`](tools/pdf_reader.py)

Script Python que automatiza la extracción de texto de los PDFs oficiales del TecNM.

**Uso:**
```bash
python3 tools/pdf_reader.py
```

**Características:**
- ✅ Extrae texto completo de PDFs preservando la estructura
- ✅ Guarda el resultado en `pdf_extracted.txt` dentro de cada skill
- ✅ Muestra preview del contenido extraído
- ✅ Identifica número de páginas y caracteres totales
- ✅ Reutilizable para todas las materias del TecNM

**Dependencias:**
```bash
pip install PyPDF2
```

**Configuración:**
El script está preconfigurado para leer el PDF de Simulación, pero puede modificarse fácilmente para cualquier otra materia cambiando las rutas `PDF_PATH` y `OUTPUT_PATH`.
